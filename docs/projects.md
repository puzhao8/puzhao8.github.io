# Software and Data

| Resource | Description |
|---|---|
| Global Wetland Watch | Global wetland maps with basin-level statistics and validation |
| SDG 6.6.1 Fresh Water | Freshwater ecosystem statistics for SDG indicator 6.6.1 |
| gww-pytorch-smp | PyTorch segmentation models for wetland mapping |
| NSW inundation | Inundation mapping for New South Wales |
| HAND from FABDEM | Height Above Nearest Drainage derived from FABDEM |

Code is available at [github.com/puzhao8](https://github.com/puzhao8) where the repositories are public.
